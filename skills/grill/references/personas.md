# Expert Personas Index

The Grill skill uses modular, lazy-loaded persona definitions. Load only the specific persona required by the target artifact:

1. [Architect](personas/architect.md) — Topology, coupling, boundaries, modularity.
2. [Senior Developer](personas/developer.md) — Idioms, defensive typing, error propagation, clean code.
3. [QA & Tester](personas/tester.md) — Boundary conditions ($0, 1, N, \text{null}$), edge cases, testability.
4. [Security Researcher](personas/security.md) — Threat models, OWASP, input sanitization, auth, secrets.
5. [Designer & DX](personas/designer_dx.md) — API ergonomics, cognitive complexity, intuitive errors.
6. [Performance Validator](personas/performance.md) — Big-O time/space, I/O bottlenecks, caching, allocations.
7. [Cost Optimizer](personas/cost.md) — Egress bloat, redundant remote queries, token waste.
8. [SRE & Reliability](personas/reliability_sre.md) — Explicit timeouts, retry jitter, circuit breaking, fallbacks.
9. [Compliance & Data Steward](personas/compliance.md) — PII redaction, data retention, audit trails, licenses.
